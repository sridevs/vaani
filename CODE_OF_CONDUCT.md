# Code of Conduct

Vaani is committed to a welcoming, respectful, and harassment-free community.

## Expected behavior

- Be considerate, constructive, and patient.
- Critique ideas and code, not people.
- Respect different backgrounds, experience levels, and communication styles.
- Protect user privacy and handle security information responsibly.
- Accept maintainer decisions made to preserve project safety and scope.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate
intimidation, doxxing, or sustained disruption are not tolerated in project
spaces.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub
profile. Maintainers may edit or remove content and temporarily or permanently
restrict participation when necessary. Reports will be handled as privately
and fairly as practical.

This code applies in repository discussions, issues, pull requests, and other
spaces where someone represents the Vaani community.
